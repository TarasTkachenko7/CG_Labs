# Лабораторная №3: текстурирование

Продолжение лабораторной №2, вариант 9 — конус. Базовая часть на оценку 3:
C++20, Vulkan, GLFW, ImGui; одна текстура альбедо из PNG-файла,
динамический uniform-буфер и вершинные/индексные буферы в памяти GPU.
Камера, направленный свет и освещение Blinn–Phong сохранены.

Конус имеет радиус 1, высоту 2 и 32 сегмента окружности: 32 боковых
треугольника и 32 треугольника основания. Для каждого треугольника нормаль
считается как `normalize(cross(B - A, C - A))`. Три вершины треугольника имеют
одну нормаль, поэтому грани видны отдельно (плоское затенение, flat shading).
Всего 64 треугольника и 192 записи вершин в буфере. Вершины дублируются,
чтобы соседние грани и основание могли иметь разные нормали.

На сцене два экземпляра конуса с одной текстурой `textures/russia.png`.
Параметры выбранного объекта меняются независимо. Текстура загружается
из файла библиотекой LodePNG и копируется через staging-буфер в `VkImage`.
Вершины и индексы также загружаются через staging-буфер в память GPU.
Для боковой поверхности UV задаются по углу и высоте, для основания —
проекцией круга на квадрат текстуры. Вершины на шве имеют U = 0 и U = 1.

## Сборка под Windows

Нужны Visual Studio 2022 с компонентом «Разработка классических приложений на C++»,
CMake и Vulkan SDK. Команда `glslc --version` должна работать из терминала.
Первое конфигурирование скачивает библиотеки с GitHub.

В PowerShell из папки проекта:

```powershell
cmake --preset msvc-debug
cmake --build build-debug --config Debug --parallel 4
.\build-debug\Debug\vulkan-starter-app.exe
```

В уже настроенной папке сборки достаточно второй команды. Для запуска также
можно открыть `build-debug/Debug/vulkan-starter-app.exe` двойным щелчком.
Рядом должны оставаться папка `shaders` с двумя файлами `.spv`
и папка `textures` с файлом `russia.png`.
Сборка создаёт и копирует эти файлы автоматически. Для замены текстуры
можно положить другой PNG под именем `textures/russia.png` и пересобрать программу.
При повторной сборке закрой запущенную программу: Windows блокирует её exe.

Сообщения валидации Vulkan выводятся в консоль.

## Сборка под Linux

При установленных компиляторе C++20, CMake, Ninja, Vulkan SDK / пакетах разработки
Vulkan и glslc:

```sh
cmake --preset debug
cmake --build build-debug --parallel 4
./build-debug/vulkan-starter-app
```

Linux-сборка здесь не проверялась.

## Настройки в ImGui

Числа можно менять перетаскиванием или вводить через Ctrl + щелчок.
Если панель не помещается по высоте, прокрутите её или сверните ненужные разделы.
В списке `Object` выбирается конус, для которого меняются материал и преобразования.

| Раздел | Параметры |
| --- | --- |
| Camera | Position; Pitch/Yaw/Roll в градусах; переключение Perspective; вертикальный FOV; Near/Far plane; Ortho size в ортографической проекции |
| Directional light | Azimuth/Elevation — направление лучей; Light color; Intensity |
| Ambient light | Ambient color; Ambient intensity |
| Material | Albedo — множитель цвета текстуры; Specular color — цвет блика; Shininess — степень, определяющая размер блика |
| Model | Перемещение, повороты и масштаб выбранного конуса |

При нулевых углах камера смотрит вдоль `-Z`; начальная позиция — `(0, 0, 5)`.
Pitch — поворот вокруг X, yaw — вокруг Y, roll — вокруг Z. FOV действует
в перспективной проекции; Ortho size задаёт половину высоты видимой области
в ортографической. Для плоскостей отсечения поддерживается `0 < near < far`.

Направленный источник задаёт параллельные лучи: у него нет позиции и затухания
с расстоянием. В шейдере направление к свету противоположно направлению лучей.
Point/spot-источники и SSBO относятся к дополнительной части и здесь не используются.
Данные передаются через один динамический UBO, `set = 0, binding = 0`.
Он содержит две структуры, по одной на объект. Шаг между структурами
выравнивается по `minUniformBufferOffsetAlignment`. При привязке общего
набора дескрипторов для каждого конуса задаётся свой байтовый сдвиг.
В том же наборе, `binding = 1`, находится пара изображение-сэмплер.
Push-константы и дополнительные эффекты текстурирования не используются.

## Клавиши из лабораторной №1

Выберите английскую раскладку и щёлкните по сцене. Удерживайте клавиши движения
и поворота. Эти клавиши изменяют **выбранный конус**; камера настраивается в ImGui.
При вводе чисел в ImGui клавиши сцены не обрабатываются.

| Клавиши | Действие |
| --- | --- |
| P | Перспективная / ортографическая проекция |
| Стрелки вверх / вниз | Поворот вокруг X |
| Стрелки влево / вправо | Поворот вокруг Y |
| Z / C | Поворот вокруг Z |
| A / D | Перемещение по X |
| W / S | Перемещение по Y |
| Q / E | Перемещение по Z |
| + / - (или цифровой блок) | Увеличение / уменьшение масштаба |
| R | Сброс всей сцены: оба конуса, камера, проекция, свет и материалы |

Кнопка `Reset scene (R)` также сбрасывает всю сцену. Масштаб модели ограничен
диапазоном 0.1–3, её перемещение — от -3 до 3 по каждой оси. Если объект вышел
из кадра после изменения камеры или модели, нажмите кнопку сброса.

## Формулы и карта кода

Вершина переводится в clip space как `P * V * M * position`.
Модель: `M = T * Rz * Ry * Rx * S`.
Для ориентации камеры `Ry(yaw) * Rx(pitch) * Rz(roll)` видовая матрица обратная:
`V = Rz(-roll) * Rx(-pitch) * Ry(-yaw) * T(-cameraPosition)`.
В матричных функциях углы заданы в радианах, значения из интерфейса переводятся
из градусов. Нормаль переводится в мировое пространство матрицей
`transpose(inverse(mat3(M)))` и нормализуется во фрагментном шейдере.

Освещение считается в мировом пространстве:

```text
L = normalize(-lightDirection)
V = normalize(cameraPosition - worldPosition)
H = normalize(L + V)
albedo = texture(albedoTexture, UV).rgb * materialColor
diffuse = max(dot(N, L), 0)
specular = pow(max(dot(N, H), 0), shininess)
color = ambientColor * ambientIntensity * albedo
      + lightColor * lightIntensity * (albedo * diffuse + specularColor * specular)
```

Блик рассчитывается только на освещённой стороне (`dot(N, L) > 0`);
шейдер также обрабатывает случаи нулевых векторов к камере и `L + V`.
Формула `V` выше относится к перспективе. В ортографической проекции лучи
наблюдения параллельны: используется постоянное направление локальной оси
`+Z` камеры, переведённое в мировое пространство.
